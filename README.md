# 縁ログ（EnLog）

友人・恋人・家族など、大切な人との関係を記録できる完全無料の個人用Webアプリです。

- サーバー不要（静的ファイルのみ）
- データはブラウザ内（localStorage）に保存され、外部には一切送信されません
- ホスティングはGitHub Pagesなどの無料枠を想定

## 1. ローカルで試す

`index.html` をブラウザで直接開くだけで動作します。インストール不要です。

## 2. 無料で公開する（GitHub Pages / iPhoneからアクセスする）

gitコマンド不要で、ブラウザだけで公開できます。

1. [github.com](https://github.com) にログインし、右上の「+」→「New repository」で新しいリポジトリを作成
   - Repository name: 例 `enlog-app`
   - Public を選択
   - 「Create repository」をクリック
2. 作成直後の画面にある「uploading an existing file」リンクをクリック
3. このフォルダの中の `index.html`、`style.css`、`app.js` の3つのファイルを画面にドラッグ＆ドロップ
   - `README.md` はアプリの動作に不要なのでアップロードしなくてOK（アップロードしても問題ありません）
4. 下部の「Commit changes」をクリックしてアップロードを確定
5. リポジトリの「Settings」タブ →左メニューの「Pages」→「Build and deployment」の Branch を `main` / `/(root)` に設定して「Save」
6. 数十秒〜数分待つと、ページ上部に公開URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）が表示されます
7. そのURLをiPhoneのSafariで開けば利用できます。Safariの共有ボタン→「ホーム画面に追加」をするとアプリのアイコンのように起動できます

## 3. 使い方

1. 「一覧」タブの「＋ 人を追加」から人物を登録
   - 名前は必須、それ以外（写真・ふりがな・関係性・タグ・誕生日・記念日・好きな食べ物・苦手な食べ物・趣味・メモ）は任意
   - 関係性は「友人・恋人・家族・知人・仕事・その他」から選択（バッジの色分けで一覧が見やすくなります）
2. 人物カードをタップすると詳細画面が開き、誕生日・記念日・好み（好き嫌いな食べ物・趣味）・メモを確認できます
3. 詳細画面の「やりとり履歴」で、会った日や話した内容を時系列で記録できます
4. 「ホーム」タブで、直近60日以内の誕生日・記念日と、最近更新した人が確認できます
5. 「一覧」タブの検索欄では、名前・ふりがな・タグ・好み・趣味・メモの内容で絞り込み検索ができます。関係性のチップでも絞り込み可能です
6. 「設定」タブでデータのエクスポート（バックアップ）・インポートが可能です

## 注意事項

- データはブラウザ単位で保存されるため、機種変更やブラウザ変更の前に必ず「エクスポート」でJSONバックアップを取ってください。
- 写真を多く登録するとブラウザの保存容量（localStorage）の上限に達することがあります。その場合はエクスポートして写真の少ないデータに整理してください。
